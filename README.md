## 👋 About Me

## 🛠️ Technologies Used
- PHP
- MySQL
- HTML
- CSS
- Bootstrap

## 📌 Project Description
This is a Book Store web application where users can:
- Browse books by category
- View book details
- Add books to cart
- Place orders

Admin features:
- Add books
- Manage orders

## ▶️ How to Run This Project
1. Install XAMPP
2. Copy project folder to `htdocs`
3. Create database in phpMyAdmin
4. Import SQL file
5. Run `localhost/project-folder-name`
